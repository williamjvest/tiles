## Key conclusions
# 1. 0xD0D3 NEVER advances over PTP — it is a static preset. Confirmed across 5 samples
#    spanning 9+ seconds during active recording. The app must run TC locally.
# 2. 0xD120 (Recording Duration) is NOT reported by FX3 (only FX6/BURANO per compat table).
#    Take runtime must be derived from the camera-confirmed REC start timestamp.
# 3. 0xD218 datatype is INT8 (SDIDataType 0x0001), NOT UINT8 (0x0002). currentUInt8()
#    returns nil on this property. Must use currentInt8() cast to Int. Range is -1..100;
#    0xFF (untaken) means no battery. Values 28–29 are plausible for a partially-charged NP-FZ100.
# 4. 0xD204/D037/D038/D039 all absent on FX3.
# 5. TC Run mode: 0x02=Free Run (confirmed at idle). In Free Run, TC should tick continuously
#    regardless of recording state. Current code gates on isRecording — wrong.
