# App Store screenshots

Tiles' own pages, drawn by `dashboard-snapshot` with demo cameras shown as real ones, each under a headline, at the
sizes App Store Connect takes:

| Folder | Device | Size |
|---|---|---|
| `ipad/` | iPad, 13-inch display, landscape | 2752 × 2064 |
| `iphone-6.3/` | iPhone 17 Pro, the size App Store Connect requires | 1206 × 2622 |
| `iphone-6.9/` | iPhone 17 Pro Max | 1320 × 2868 |
| `mac/` | Mac | 2880 × 1800 |

`python3 scripts/screenshots.py` makes them again, along with the README's screenshots in `docs/images`. The headlines
and which cameras each one shows are in that script.
